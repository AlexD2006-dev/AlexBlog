# Alex' Blog 🐍

A personal blog built with Node.js, Express, EJS, HTML and CSS. Slytherin themed 🐍

## Tech Stack
- **Backend:** Node.js, Express
- **Templating:** EJS
- **Database:** MongoDB (coming soon)
- **Frontend:** HTML, CSS
- **Other:** Nodemon, Custom Logger Middleware

## Features
- 📝 Blog posts
- 📧 Contact form
- 🎨 Slytherin themed design
